API Documentation

Resume Upload and Processing

POST /upload-files-process/

Upload and process resume files to extract candidate information.

Format: multipart/form-data

Required fields:

  • files: List of files (PDF, DOCX)
  • session_cookie: Authentication token

Job Description Creation

POST /create-job-description/

Create standardized job descriptions with optional AI assistance.

Format: multipart/form-data

Fields:

  • job_title: Title of the position
  • job_description: General description
  • job_location: Location
  • job_type: Employment type
  • job_skills: Required skills
  • ai_feature: Set to "1" to use AI assistance
  • Additional fields available for comprehensive descriptions
